## Import

```tsx
import { Surface } from "@fried-ui/react";
```

## Usage

<Preview>
  <SurfaceDemo />
</Preview>

```tsx
<Surface className="p-6">
  <h2>Card Title</h2>
  <p>Content goes here.</p>
</Surface>
```

## Variants

The `variant` prop controls the visual style of the surface.

<Preview>
  <SurfaceVariants />
</Preview>

```tsx
<Surface variant="default">Default</Surface>
<Surface variant="bordered">Bordered</Surface>
<Surface variant="glass">Glass</Surface>
<Surface variant="primary">Primary</Surface>
```

## Radius

The `radius` prop controls border-radius.

<Preview>
  <SurfaceRadius />
</Preview>

```tsx
<Surface radius="none">none</Surface>
<Surface radius="sm">sm</Surface>
<Surface radius="md">md</Surface>
<Surface radius="lg">lg</Surface>
<Surface radius="xl">xl</Surface>
```

## API Reference

### Surface Props

| Prop        | Type                                                                                                            | Default     | Description              |
| ----------- | --------------------------------------------------------------------------------------------------------------- | ----------- | ------------------------ |
| `variant`   | `"default"` \| `"default-bordered"` \| `"plain"` \| `"plain-bordered"` \| `"glass"` \| `"frost"` \| `"overlay"` | `"default"` | The visual variant       |
| `radius`    | `"none"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"`                                                                | `"md"`      | Border radius            |
| `shadow`    | `"none"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"`                                                                | `"none"`    | Elevation shadow         |
| `className` | `string`                                                                                                        | -           | Additional CSS classes   |
| `ref`       | `Ref<HTMLDivElement>`                                                                                           | -           | Forwarded ref to the div |
| `children`  | `ReactNode`                                                                                                     | -           | Surface content          |

### CSS Classes

| Class                           | Description          |
| ------------------------------- | -------------------- |
| `fri-surface`                   | Base styles          |
| `fri-surface--default`          | Default variant      |
| `fri-surface--default-bordered` | Default + border     |
| `fri-surface--plain`            | Plain variant        |
| `fri-surface--plain-bordered`   | Plain + border       |
| `fri-surface--glass`            | Glass variant        |
| `fri-surface--frost`            | Frost variant        |
| `fri-surface--overlay`          | Overlay variant      |
| `fri-surface--radius-none`      | No border radius     |
| `fri-surface--radius-sm`        | Small border radius  |
| `fri-surface--radius-md`        | Medium border radius |
| `fri-surface--radius-lg`        | Large border radius  |
| `fri-surface--radius-xl`        | Extra large radius   |
| `fri-surface--shadow-none`      | No shadow            |
| `fri-surface--shadow-sm`        | Small shadow         |
| `fri-surface--shadow-md`        | Medium shadow        |
| `fri-surface--shadow-lg`        | Large shadow         |
| `fri-surface--shadow-xl`        | Extra large shadow   |
