# @fried-ui/styles

**Pure CSS for Fried UI — same class in HTML, no React needed.**

Design tokens, component classes, dual selectors, dark mode.

## Installation

```bash
pnpm add @fried-ui/styles
```

Peer dependency: `tailwindcss >=4.0.0`

## Usage

Import styles in your CSS entry file:

```css
@import "tailwindcss";
@import "@fried-ui/styles";
```

## Development

```bash
pnpm dev     # Watch mode
pnpm build   # Build
```
